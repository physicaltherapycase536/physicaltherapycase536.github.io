01. Giới thiệu

Tốt nghiệp ngành Kỹ thuật Điều khiển & Tự động hóa chất lượng cao tại ĐHBK Hà Nội (GPA 3.2/4.0). Tôi bắt đầu với robotics và xử lý ảnh, rồi chuyển sâu vào lập trình hệ thống nhúng — nơi phần cứng và phần mềm giao thoa.

Tôi tập trung vào C/C++ hệ thống: đa luồng POSIX, IPC, TCP/IP socket, Protobuf và firmware cho Embedded Linux. Triết lý làm việc: hiểu phần cứng, viết code rõ ràng, đo đạc thay vì phỏng đoán, và luôn có unit test.

Ngoài giờ làm, tôi nghiên cứu kiến trúc hệ thống nhúng thời gian thực, tìm hiểu giao thức mới và đọc datasheet.

03. Dự án

Các dự án thực tế tôi đã tham gia và đóng góp chính.

Firmware System Manager

Firmware nhúng trên Embedded Linux cho hệ thống quang-điện tử dựa FPGA (Gimbal, Camera ngày/đêm, Laser Range Finder). Kiến trúc đa luồng POSIX, giao tiếp HPC qua TCP/IP + Protobuf, truy cập FPGA qua mmap.

  • C++
  • Embedded Linux
  • POSIX Threads
  • TCP/IP
  • Protobuf

OTA Client — Pyrenee Drive ADAS

OTA client nhúng cho thiết bị ADAS Jetson Orin NX: daemon ota-clientd và CLI otactl bằng C++17, AF_UNIX IPC, cập nhật firmware qua AWS S3/CloudFront, rollback, CI/static analysis, cross-compile ARM64.

  • C++17
  • IPC
  • Jetson Orin NX
  • AWS S3
  • CMake
  • Docker
  • GitHub Actions

Konica Minolta Printer Driver

Nhóm 30 người tại FPT Software: lập trình IPv6 Single Stack, sửa xung đột IPv4/IPv6, viết tài liệu cho khách hàng, tham gia phát triển và sửa lỗi driver V3/V4, viết unit test bằng Google Test.
